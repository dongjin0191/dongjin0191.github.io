라파일정표

홈 화면에 앱으로 설치하기

아이폰 (Safari)

  1. 이 주소를 Safari에서 엽니다.
  2. 아래쪽 공유 버튼(□↑)을 누릅니다.
  3. 홈 화면에 추가 → 추가.

갤럭시 (Chrome·삼성 인터넷)

  1. 이 주소를 Chrome 또는 삼성 인터넷에서 엽니다.
  2. 오른쪽 위 ⋮ (삼성 인터넷은 아래 ≡)를 누릅니다.
  3. 앱 설치 또는 홈 화면에 추가 → 설치.

PC (Chrome·Edge)

  1. 이 주소를 Chrome 또는 Edge에서 엽니다.
  2. 주소창 오른쪽 설치 아이콘(⊕) 또는 ⋮ → 앱 → 이 사이트를 앱으로 설치.
  3. 바탕화면·작업표시줄에 ‘라파일정표’ 아이콘이 생깁니다.

로그인 없이 바로 열리고, 한 번 연 뒤에는 인터넷이 없어도 열립니다.
