홈 화면에 앱으로 설치하기

아이폰 (Safari)

  1. 이 주소를 Safari에서 엽니다.
  2. 아래쪽 공유 버튼(□↑)을 누릅니다.
  3. 홈 화면에 추가 → 추가.

갤럭시 (Chrome·삼성 인터넷)

  1. 이 주소를 Chrome 또는 삼성 인터넷에서 엽니다.
  2. 오른쪽 위 ⋮ (삼성 인터넷은 아래 ≡)를 누릅니다.
  3. 앱 설치 또는 홈 화면에 추가 → 설치.

PC (Chrome·Edge)

  1. 이 주소를 Chrome 또는 Edge에서 엽니다.
  2. 주소창 오른쪽 설치 아이콘(⊕) 또는 ⋮ → 앱 → 이 사이트를 앱으로 설치.
  3. 바탕화면·작업표시줄에 ‘라파일정표’ 아이콘이 생깁니다.

로그인 없이 바로 열리고, 한 번 연 뒤에는 인터넷이 없어도 열립니다.

구독 열기

갤럭시 (구글 캘린더)

  1. PC에서 calendar.google.com을 엽니다.
  2. 왼쪽 다른 캘린더 ＋ → URL로 추가에 위 주소를 붙여넣습니다.
  3. 폰의 구글·삼성 캘린더에 자동으로 나타납니다.

PC (Outlook)

  1. 캘린더 추가 → 웹에서 구독.
  2. 위 주소를 붙여넣고 가져오기.

한 번만 구독해 두면 일정이 바뀔 때 캘린더에도 자동으로 반영됩니다. 캘린더 앱에 따라 반영까지 몇 시간 걸릴 수 있습니다.
